## 四、核心功能
1. 支持 **Residence / Land / Towny / 自定义区域** 的袭击系统。
2. **全 GUI 配置**，无需写配置文件，游戏内即可完成袭击配置
3. 袭击阶段分类（**准备 / 倒计时 / 战斗**）
4. **丰富的袭击玩法**<font style="color:#DF2A3F;">（部分为进阶版专属）</font>
5. **可自定义不祥征兆**
6. **高度自定义信息显示**（支持`聊天栏消息`/`动作栏`/`标题`）与 **自定义音效**。
7. 支持 **MythicMobs 掉落自定义不祥征兆效果**：`customraidsomen{omen=<id>;level=<n>}`。
8. **支持自定义奖励、实时计分板排行、伤害排行结算**。
9. **内置自定义区域**（无需领地插件也可用）。
10. 每周**定时袭击活动** <font style="color:#DF2A3F;">(进阶版功能)</font>

## 五、运行要求
+ Paper 或 Folia 1.20.x+
+ Java 21
+ MythicMobs<font style="color:#DF2A3F;">（必须）</font>
+ ProtocolLib（<font style="color:#DF2A3F;">Folia 必须</font>）
+ 袭击区域 支持<font style="color:rgb(65, 65, 129);"> </font>**Lands / Residence / Towny / 内置自定义区域**

## 六、Folia 支持
+ Folia 服如需完整侧边计分板显示，<font style="color:#DF2A3F;">请安装 </font>`<font style="color:#DF2A3F;">ProtocolLib</font>`。
