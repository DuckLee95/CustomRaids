# CustomRaids Overview

CustomRaids is a custom raid plugin inspired by Minecraft village raids. It supports Paper and Folia 1.20+ servers. Players can defend Lands, Residence, Towny, or built-in custom regions together, defeat waves of mobs, and earn rewards.

Both raids and Omens can be configured through an in-game GUI. Messages, sounds, and other display elements are also fully customizable.

![CustomRaids plugin overview](../../images/profile.png)

## Key Features

1. Supports Lands, Residence, Towny, and built-in custom regions.
2. Create and manage raids through the GUI without manually editing configuration files.
3. Provides preparation, countdown, and combat phases.
4. Supports wave raids and challenge raids (some features require the Pro edition).
5. Supports custom Omens.
6. Supports custom chat messages, ActionBars, Titles, and sounds.
7. Supports custom Omen drops through MythicMobs: `customraidsomen{omen=<id>;level=<n>}`.
8. Supports custom rewards, live scoreboards, and damage-ranking payouts.
9. Includes built-in custom regions that do not require a region plugin.
10. Supports scheduled weekly raid events (Pro edition).
11. Includes Chinese and English language files, with fully customizable display text.

## Requirements

- **Server:** Paper or Folia 1.20+
- **Java:** Java 21
- **Required dependency:** MythicMobs
- **Required on Folia:** ProtocolLib
- **Supported raid regions:** Lands, Residence, Towny, and built-in custom regions

## Free and Pro Editions

- **Free edition:** Supports up to three standard raids.
- **Pro edition:** Unlocks all features and includes after-sales support, troubleshooting assistance, and a feature-request channel.

The Pro edition costs CNY 30 and is available on [Afdian](https://ifdian.net/a/yyyork).
