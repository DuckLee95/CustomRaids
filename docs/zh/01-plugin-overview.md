# CustomRaids 简介

CustomRaids 是一款受 Minecraft 村庄袭击启发的自定义袭击插件，适用于 Paper 和 Folia 1.20+ 服务端。玩家可以共同防御 Lands、Residence、Towny 或内置自定义区域，击败多波怪物并获得奖励。

袭击与 Omen 均支持 GUI 配置，消息、音效和显示内容也可以自定义。

![CustomRaids 插件概览](../../images/profile.png)

## 核心功能

1. 支持 Lands、Residence、Towny 和内置自定义区域。
2. 支持通过 GUI 创建和管理袭击，无需手动编辑配置文件。
3. 提供准备、倒计时和战斗等袭击阶段。
4. 支持波次袭击和挑战袭击（部分功能为进阶版专属）。
5. 支持自定义 Omen。
6. 支持自定义聊天消息、ActionBar、Title 和音效。
7. 支持通过 MythicMobs 掉落自定义 Omen：`customraidsomen{omen=<id>;level=<n>}`。
8. 支持自定义奖励、实时计分板和伤害排行结算。
9. 提供无需领地插件的内置自定义区域。
10. 支持每周定时袭击活动（进阶版功能）。
11. 内置中文和英文语言文件，且显示文本均可自定义。

## 运行要求

- **服务端：** Paper 或 Folia 1.20+
- **Java：** Java 21
- **必需依赖：** MythicMobs
- **Folia 必需依赖：** ProtocolLib
- **支持的袭击区域：** Lands、Residence、Towny、内置自定义区域

## 免费版与进阶版

- **免费版：** 最多可设置 3 个普通袭击。
- **进阶版：** 解锁全部功能，并提供售后支持、问题协助和功能建议反馈渠道。

进阶版价格为 30 元，可前往[爱发电](https://ifdian.net/a/yyyork)购买。
